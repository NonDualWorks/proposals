# CLAUDE.md

This repo holds design proposals for the Nondual Works suite. It is documents, not code.

Before doing anything, read [HANDOFF.md](HANDOFF.md) for current state and next steps, then [RFC-0000](rfcs/0000-proposal-process.md) for the process.

Rules when working here:

- Follow the process in RFC-0000, including for changes to the process itself (those are Lite Proposals at minimum).
- Never edit `templates/` in place for a proposal; copy the template.
- Keep front matter values to the vocabularies listed in HANDOFF.md.
- Keep *Open questions* honest; move resolved ones to *Answered questions* with the answer, never delete them.
- Write in the Concourse RFC style described in CONTRIBUTING.md: first person, concrete examples before abstractions.
- The maintainer and decider is @PhanidharX. Don't mark anything accepted, declined or merged on their behalf; draft, then leave the decision to them.
- After any phase change, update *Where things stand* in HANDOFF.md and the index in MAP.md.
